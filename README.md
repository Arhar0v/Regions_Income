# Регионы России: Анализ доходов и планирования
Данный проект посвящен исследованию, обработке и визуализации данных о поступлениях денежных средств в бюджеты регионов Российской Федерации. В рамках работы были обработаны исходные датасеты, проведен разведочный анализ данных (EDA) и созданы интерактивные дашборды для мониторинга исполнения бюджетов.

## 📊 Ссылки на интерактивные дашборды (Yandex DataLens)
Результаты исследования визуализированы в двух дашбордах:
1. **[Дашборд 1: Общий анализ доходов регионов](https://datalens.yandex/48h7b9ehdnpin?_share_link=public)**
2. **[Дашборд 2: Анализ доходов регионов по годам](https://datalens.yandex/48h7b9ehdnpin?_share_link=public)**

## 📁 Структура репозитория
* **`processed_data/`** — Исходные данные, полученные по техническому заданию;
* **`source_data/`** — Обработанные данные, полученные посредством работы файла `RU_Regions_Income.ipynb`;
* **`RU_Regions_Income.ipynb`** — Jupyter Notebook с кодом обработки датасетов;
* **`README.md`** — Описание проекта.
